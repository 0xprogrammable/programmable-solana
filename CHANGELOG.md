# Changelog

All notable changes to published protocol components will be documented here.
Each release section is grouped by component so independent package versions do
not imply one repository-wide release number. A component may receive its own
changelog when it acquires an independent release cycle.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and
released packages follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html).
